# Demo typography

Locally bundled original font files; no remote font service is required.

- Chinese: Xiaolai Regular v3.126, https://github.com/lxgw/kose-font/releases/tag/v3.126
  - License: Xiaolai-OFL.txt
- Latin: Shadows Into Light Regular, https://github.com/google/fonts/tree/main/ofl/shadowsintolight
  - License: ShadowsIntoLight-OFL.txt

Both fonts are distributed under SIL Open Font License 1.1. Original font
binaries are unmodified. Slightly elongated glyphs and irregular baselines
are a CSS treatment limited to the demo's headings.
